WordPress

Plugins y mejoras

Decisiones tomadas para mejorar la web mediante plugins de WordPress y una mejor organización del contenido.

Qué se ha mejorado

La instalación de WordPress se ha ampliado con una serie de ajustes orientados a mejorar la presentación del proyecto, facilitar la gestión del contenido y hacer la navegación más clara. El objetivo no ha sido añadir plugins sin criterio, sino reforzar la experiencia de usuario y aprovechar mejor las posibilidades del gestor.

  • Personalización visual de páginas clave para mantener una identidad coherente.
  • Separación clara entre páginas informativas y blog de WordPress.
  • Navegación por categorías y etiquetas para ordenar mejor el contenido.
  • Diseño responsive adaptado a móvil, tablet y escritorio.
  • Uso del editor de bloques solo en los apartados donde realmente aporta agilidad.

Plugins utilizados

Contact Form 7

Formulario

Se utiliza para gestionar el formulario de contacto de manera sencilla dentro de WordPress. Aporta una solución estable, ampliamente usada y fácil de mantener para recoger mensajes desde la página de contacto.

Yoast SEO

Visibilidad

Se propone para optimizar títulos, descripciones y estructura básica de posicionamiento. Aunque el proyecto es académico, mejora la forma en que WordPress organiza y presenta cada página y entrada.

WPS Hide Login

Acceso

Se utiliza para cambiar la URL de acceso por defecto de WordPress y evitar que cualquier usuario pueda localizar fácilmente rutas típicas como wp-login.php o wp-admin. Es una mejora sencilla para reforzar el acceso al panel en una web publicada en un dominio real.

LiteSpeed Cache

Rendimiento

Se recomienda si el hosting lo soporta correctamente. Su función es mejorar el rendimiento y la velocidad de carga mediante caché y optimización, algo útil en una web con bastante peso visual e imágenes destacadas.

Por qué estas decisiones aportan valor

  • Mejoran la experiencia de navegación respecto a una instalación básica.
  • Permiten mantener una identidad visual coherente en todas las páginas.
  • Facilitan que el blog use categorías, etiquetas y navegación propia de WordPress.
  • Hacen más sencillo el mantenimiento del contenido desde el panel.
  • Demuestran un uso más cuidado de WordPress como gestor de contenidos.

Categorías y etiquetas usadas

Para ordenar el blog y facilitar la navegación, se han planteado categorías y etiquetas coherentes con el contenido real de la web. De esta forma, las entradas no aparecen aisladas, sino agrupadas por temática.

  • Categorías: Aparición en prensa, Premios, Tecnología & IA, Marketing & Creación de Contenido.
  • Etiquetas: marca personal, creación de contenido, UPSA, emprendimiento, proyectos, TikTok, Instagram, YouTube, IA, hackathon, premios, fintech, AWS, diseño, desarrollo web, producto digital, criterio, foco y productividad.
Base visual Diseño adaptado

La parte visual se ha ajustado para que WordPress mantenga una presentación coherente con el proyecto, sin depender únicamente de la maquetación estándar del editor.

Objetivo Menos Gutenberg

La web se plantea para que el editor de bloques se utilice solo cuando agiliza el trabajo, evitando complicar la maquetación de las páginas más importantes.
